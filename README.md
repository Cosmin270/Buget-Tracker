# 💸 Smart Budget Tracker

A full-stack expense tracking application that helps users visualize their spending habits, track budget adherence, and manage transaction history. Built with the PERN stack (PostgreSQL/SQLite, Express, React, Node).
## 🚀 Features

* **Real-time Dashboard:** Instant overview of total spent vs. remaining budget.
* **Visual Analytics:** Interactive donut chart breaking down spending by category (powered by Recharts).
* **Budget Tracking:** Dynamic progress bar that changes color based on budget utilization.
* **Transaction Management:** Add new expenses and delete old ones with instant UI updates.
* **Responsive Design:** Fully responsive UI built with Tailwind CSS.

## 🛠️ Tech Stack

**Frontend:**
* React (Vite)
* Tailwind CSS (Styling)
* Recharts (Data Visualization)
* Lucide React (Icons)
* Axios (API Integration)

**Backend:**
* Node.js & Express.js
* Prisma ORM
* SQLite (Dev) / PostgreSQL (Prod)
